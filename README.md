# Hi, I'm Kamogelo 👋

I’m a **Full Stack Developer** specialising in **React**, Redux, Next.js, **TypeScript**, **Node.js**, and Express.js. I take full ownership of the end-to-end pipeline, from architecting secure RESTful APIs and managing **PostgreSQL** databases, to containerising with Docker.

On the backend, I ensure reliable data flow using Supabase and Prisma ORM, alongside NoSQL solutions with MongoDB and Mongoose.

On the client side, I craft responsive, modern frontends that prioritize a seamless user experience. Using JavaScript and Tailwind CSS, I build clean, component-driven interfaces that are intuitive and fast.

I believe in shipping stable code with absolute confidence. To maintain high engineering standards, I test rigorously with Jest and Vitest, and automate delivery through seamless CI/CD pipelines.

Currently expanding my cloud expertise with Microsoft Azure, I have spent the last 2 years building and shipping functional web software and internal tools that solve real business problems for tech start-ups.
